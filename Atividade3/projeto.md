# Projeto

## Pseudocodigo

- Sistema inicia
- Sistema solicita nome da disciplina
- Sistema registra em vetor
- Sistema solicita quantidade de notas
- Sistema solicita nota 1,2,...,x
- Sistema chama funcao para calculo de media
- Sistema chama funcao para definicao conceito
- Sistema retorna conceito e registra em vetor
- Sistema chama funcao para validacao de aproveitamento
- Sistema registra retorno no vetor
- Sistema informa ao usuario resultado final
