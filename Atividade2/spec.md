# Caixa eletrônico

## Paradigma: Declarativo

## Pseudocódigo

1.0 Inicio do programa  
Menu principal  
Informar opções:  
1.1 Consultar Saldo 
1.2 Depositar
1.3 Sacar
1.4 Sair  

1.1 Consultar Saldo   
1.1.1 Sistema deve informar saldo atual

1.2 Depositar  
1.1.1 Ler valor a depositar
1.1.2 Sistema deve atualizar saldo do cliente 
1.1.3 Sistema deve informar saldo atual  

1.3 Sacar
1.3.1 Ler valor a sacar
1.3.2 Sistema deve validar se há saldo suficiente
1.3.3.1 Para saldo insuficiente, sistema deve infomar que valor não pode ser sacado e solicitar novo
1.3.3.2 Para saldo suficiente, sistema deve informar que valor foi liberado
1.3.4 Sistema deve informar saldo atual

1.4 Sair 
1.4.1 Encerrar sistema
